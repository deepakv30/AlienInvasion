# Security Policy

## Supported Versions

This is a small educational / portfolio project. The latest version on the `main` branch is the only actively maintained version.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Preferred method:**

1. Open a private security advisory on GitHub (recommended), or
2. Open a regular issue with the `bug` label if the issue is not sensitive, or
3. Contact the repository owner directly via their GitHub profile.

Please include:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge reports as quickly as possible and work to address valid issues.

Thank you for helping keep the project safe.
